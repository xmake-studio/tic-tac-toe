# Крестики-нолики

Учебный проект: сервис игры «Крестики-нолики» против компьютера.

Пользователь играет крестиками (`X`) и всегда ходит первым, программа играет ноликами (`O`).
Логика хода программы: если одним ходом можно выиграть — программа выигрывает, иначе ходит в случайную свободную клетку.

## Структура

```
tictactoe/
    board.py   — поле 3x3: ходы, проверка победителя и ничьей
    bot.py     — выбор хода программы
    game.py    — партия: ход пользователя, ответ программы, статус игры
tests/         — тесты pytest
main.py        — примеры использования классов
```

Статусы игры: `in_progress`, `player_won`, `bot_won`, `draw`.

Координаты клетки — номер строки и столбца от 0 до 2.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Тесты

```bash
pytest --cov
```

Покрытие считается по веткам (настройки в `setup.cfg`), требуется 100%.

## CI и линтер

На каждый push и pull request GitHub Actions (`.github/workflows/ci.yml`) запускает:

- `flake8 .` — проверка PEP 8;
- `pytest --cov` — тесты и проверка покрытия.

Те же проверки можно запускать локально перед коммитом через git hook:

```bash
git config core.hooksPath hooks
```

## Заметки к реализации

- Поле хранится как список 3x3, пустая клетка — `None`.
- Генератор случайных чисел передаётся в `Bot` через конструктор, чтобы в тестах ход программы был предсказуемым.
- Неверный ход (клетка занята или вне поля) вызывает `InvalidMoveError`, ход в законченной игре — `GameFinishedError`.
